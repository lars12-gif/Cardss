# بوت جمع أرقام جهات الاتصال — Baileys

بوت واتساب بسيط بـ JavaScript ومكتبة Baileys. الربط يتم برمز الاقتران، ويستخرج أرقام الهواتف من رسائل vCard فقط. لا يرسل رسائل إلى جهات الاتصال المستخرجة.

## المتطلبات
- Node.js 20 أو أحدث
- رقم واتساب مخصص لتشغيل البوت
- استضافة تدعم تشغيل Node.js باستمرار

## التثبيت والتشغيل
1. ارفع المشروع إلى GitHub أو إلى الاستضافة.
2. انسخ `.env.example` إلى ملف باسم `.env`.
3. عدّل `BOT_NUMBER` واكتب رقم واتساب المستخدم للربط بصيغة دولية، أرقام فقط، من دون `+`.
   - مثال عراقي: `9647XXXXXXXXX`
4. ثبّت الحزم:
   ```bash
   npm install
   ```
5. شغّل البوت:
   ```bash
   npm start
   ```
6. سيظهر رمز الاقتران في سجل التشغيل (Logs).
7. من واتساب في الهاتف: **الأجهزة المرتبطة > ربط جهاز > الربط باستخدام رقم الهاتف**، ثم أدخل الرمز الظاهر.

بعد نجاح الربط، لا تحذف مجلد `auth_info` لأنه يحتوي جلسة واتساب.

## الأوامر
- `$احسب` — يبدأ عملية جديدة ويمسح نتائج العملية السابقة في المحادثة نفسها.
- أرسل جهة اتصال أو عدة جهات بصيغة vCard.
- `$ناتج` — يوقف الجمع ويرسل رسالة أولى تحتوي الأرقام فقط، كل رقم بسطر ويبدأ بـ `+`، ثم رسالة ثانية مستقلة فيها الملخص.

## منع التكرار وطريقة الحساب
- الرقم المكرر لا يضاف إلى قائمة النتائج مرة ثانية.
- `الناجحة`: عدد أرقام الهواتف الفريدة التي تم استخراجها.
- `الفاشلة`: عدد بطاقات vCard التي لم ينتج عنها رقم صالح.
- `المكررة`: عدد مرات تكرار الأرقام التي سبق حفظها أثناء العملية.
- `إجمالي الجهات المستلمة`: عدد بطاقات vCard المستلمة.
- قد تحتوي بطاقة واحدة على أكثر من رقم؛ لذلك مجموع الأرقام الناجحة والفاشلة والمكررة قد لا يساوي عدد البطاقات المستلمة حرفياً.

## إعدادات `.env`
- `DEFAULT_COUNTRY_CODE=964`: رمز الدولة الافتراضي للأرقام المحلية التي لا تحتوي رمز دولة. غيّره إذا كنت تستخدم دولة أخرى.
- `GROUPS_ONLY=true`: يجعل البوت يعمل داخل المجموعات فقط. القيمة الافتراضية `false`.
- `OWNER_NUMBER`: ضع رقم المشغّل الدولي لتقييد الأوامر عليه. اتركه فارغاً للسماح لأي شخص في المحادثة.
- `DATA_FILE`: مسار ملف حفظ بيانات الجمع.

## ملاحظات مهمة
- يجب أن تصل جهة الاتصال كرسالة WhatsApp Contact/vCard. الصور أو النصوص التي تحتوي أرقاماً لن تُقرأ.
- الأرقام التي لا تحتوي رمز دولة تُفسّر باستخدام `DEFAULT_COUNTRY_CODE`. الأرقام الدولية التي تبدأ بـ `+` أو `00` تُحفظ كما هي بعد تنظيف التنسيق.
- التحقق هنا تنسيقي أساسي وليس تحققاً من أن الرقم مخصص فعلاً أو أن واتساب مسجل عليه.
- عند إعادة تشغيل البوت، تبقى النتائج محفوظة في ملف البيانات. أرسل `$احسب` لبدء عملية جديدة.
- لا ترفع `.env` أو `auth_info` إلى GitHub، ولا تشارك رمز الاقتران أو ملفات الجلسة.
- التزم بالحصول على موافقة مناسبة قبل جمع أو استخدام أرقام الآخرين.
