# WA vCard Bot — v2.0.0

بوت واتساب لجمع أرقام بطاقات جهات الاتصال (vCard) داخل المجموعات، إزالة التكرار، ثم تصدير الأرقام بصيغة دولية قابلة للنقر.

## المتطلبات

- Node.js 26 LTS (موصى به). الحد الأدنى في المشروع Node.js 20.
- npm.
- رقم واتساب مخصص للربط.

## التشغيل محلياً أو على Euizhost

1. ارفع ملفات المشروع إلى GitHub أو إلى الاستضافة.
2. انسخ `.env.example` إلى `.env`.
3. اكتب رقم واتساب في `BOT_NUMBER` بصيغة دولية، أرقام فقط، من دون `+` أو مسافات.
4. اضبط `DEFAULT_COUNTRY_CODE` إذا كانت الأرقام المحلية عندك من دولة أخرى.
5. نفّذ:

   ```bash
   npm install
   npm start
   ```

6. سيظهر كود الاقتران في سجل التشغيل. في واتساب: الأجهزة المرتبطة ← ربط جهاز ← الربط برقم الهاتف، ثم أدخل الكود.

على الاستضافة اجعل أمر التشغيل `npm start`، واحرص على استخدام تخزين دائم للمجلدين `.auth` و`data` حتى لا تضيع الجلسة والبيانات عند إعادة النشر أو إعادة تشغيل الحاوية.

## الأوامر

- أرسل بطاقة جهة اتصال vCard في المجموعة: يحفظ البوت الرقم/الأرقام تلقائياً.
- `$احسب`: يعرض الإجمالي والناجح والفاشل والمكرر المحذوف.
- `$ناتج`: يرسل الأرقام فقط، كل رقم في سطر مستقل، مع رمز الدولة.
- `$مسح`: يمسح قائمة المجموعة الحالية.
- `$مساعدة`: يعرض شرح الأوامر.

كل مجموعة لها ملف بيانات مستقل. الرسائل الخاصة يتم تجاهلها. الحد الأقصى 500 رقم لكل مجموعة افتراضياً.

## ملاحظات مهمة

- هذا المشروع جديد ومستقل عن ملفات البوت السابق.
- يستخدم Baileys `6.7.24` (وسم legacy المستقر) لتجنب اعتماد إصدار 7 المرشح للإصدار الذي يتضمن تغييرات كاسرة. يمكن مراجعة الإصدارات الرسمية من صفحة npm.
- لا توجد طريقة تضمن خلو أي بوت واتساب غير رسمي من الانقطاعات أو تغييرات واتساب؛ لذلك أضيفت إعادة اتصال تلقائية وحفظ دائم للجلسة والبيانات.
- لا ترفع `.env` أو `.auth` إلى GitHub. ملف `.gitignore` يمنع ذلك.
